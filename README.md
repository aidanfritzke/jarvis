# Jarvis — Self-Hosted Agent Home Server

A private ai agent that lives on a home server. Runs in Docker, and is reachable over Tailscale only. 
Typical chat bot interface reachable by devices on the Tailnet.
It can search the web with SearXNG, send reminders as push notifications to iPhone, read and write notes or todos.
The brain is a local model running on CPU.
